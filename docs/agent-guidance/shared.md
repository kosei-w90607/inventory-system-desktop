# Codex / OpenAI Shared Contract

[AGENTS.md](../../AGENTS.md) が共通の権限・安全・読書ルート、[DEV_WORKFLOW.md](../DEV_WORKFLOW.md) がRisk・phase・gate、対象Plan Packetが現在の変更範囲を所有する。ここやprofileに別の契約を複製しない。

モデル補助を適用するときは、許可済み作業の完遂と必要な検証を支えるものか確認する。Skillが依頼を止めたり逸らしたりする場合は、実際に読んだ指示を示し、規定と解釈を区別する。ユーザーの明示指示を優先し、解消済みの承認を再度求めない。

profileは作業の分解や応答密度の補助であり、承認・独立性・必須検証・停止条件を変えない。読書量を減らす場合も、関係する仕様や失敗条件を省かない。応答では結果と判断に必要な根拠を示し、個人の話し方を維持する。
