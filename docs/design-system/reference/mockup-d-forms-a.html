D の要点（商品登録・修正、Lane 2 実装値へ同期）: これを採ると何が変わるか — 入力欄・select・textarea の枠が `--border`（#cdc8c4、対 `--background` 1.59:1）から `--border-strong`（#8a8480、対 `--background` 3.53:1）へ濃くなり、静止時でも操作対象と分かる。button / card / FormSection 枠は `--border` 濃化のみに留め border-strong 化しない（D-7 Non-scope、Lane 3〜5 sweep 対象）。
  1. 操作枠のコントラスト: 入力欄・select・textarea の枠を `--border`（#cdc8c4、1.59:1）から `--border-strong`（#8a8480、対 `--background` 3.53:1、WCAG 相対輝度で独立再計算した値。旧 3.69:1 は誤記で本 mockup 更新時に訂正）へ。button・card・FormSection の枠は `--border` 濃化のみ（Lane 2 では border-strong 化しない、Non-scope）。文字は変えない。
  2. 価格履歴は一覧と同じ `.tbl`（sticky header 対象、行数が増えても崩れない）。
  3. 必須項目は色ではなく「（必須）」の文字と、エラーは icon + 赤文字 + 具体的な直し方（04-backbone 原則 3）。
  4. page root の余白統一: 本画面の `.page{gap:24px}` は `PageShell`（`space-y-6`）の実装値。上部の比較パネルは旧 `space-y-4`（16px、3 系統の 1 つ）との前後比較（Lane 2 で PageShell が 43 箇所を統一）。
現仕様維持（D の対象外）: セクション分割・read-only の muted 背景・「廃番にする」確認ダイアログの要否・「レジにバーコード登録する」の挙動は 51-ui の契約どおりで、D は見た目に手を入れていない。
未決（doc にない文言・値を仮に置いた箇所）: 保存ボタン文言「保存する」（51-ui は button 文言を明記していない）／「レジ在庫連携」ラベル（51-ui は `pos_stock_sync` の説明文のみで表示ラベルを明記していない、実装時に既存 UI-01b の実 label を確認する）／原価 -50・商品名空欄は validation 表示のための仮値。「編集内容が保存されていません」等は UI_TECH_STACK §6.11 UI-USW-D2 の正本文言をそのまま使用（未決ではない）。
