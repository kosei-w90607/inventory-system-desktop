D の要点（差分のみ・番号付き未決項目）
  1. 総件数と現在位置を上にも（DSR-22）: 統一形「238 件中 1〜50 件目 · 1 / 5 ページ」を table 直上に text 表示（必須）。pager ボタンは任意で、本 mockup では上部に置かず下部のみに置く（catalog ⑩ Don't）— これを採ると何が変わるか: 長い一覧で「いま何件目か」を下までスクロールせずに確認でき、同じ操作ボタンを 2 組出さないため判断コストも増えない。viewport を超えない短い一覧では省略してよいか（catalog ⑩ opt-in 条件）は未決。
  2. table header を sticky: 列名が常に見える。これを採ると何が変わるか: 横スクロール中も列の意味を見失わない。sticky header の背景色は `--d-head`（stone-100 相当）でよいか、カード地色 `--card` のままでよいかは未決。
  3. 識別列（商品コード + 商品名）を左固定: 横スクロール時に右端へ影。識別列固定を持たない履歴系画面は日時 + 種別を固定する方針（catalog ⑯ 必須構成 4）だが、対象画面リストの最終確定は Lane 2 実装時。
  4. 操作枠・構造線のコントラスト（DSR-22 原則 13）: 構造線 `--border` を一段濃く（提案 #cdc8c4）、操作枠 `--border-strong`（提案 #8a8480）を新設。実測値は Lane 2 の L3 で確定（本 mockup は提案値のみ）。
  5. 現在行 3 点（DSR-22 原則 15）: 左 4px バー + 淡い背景 `--row-current` + badge/文言。表内の 3 行目に適用例あり（下にスクロールして確認）。badge/文言の具体的な語彙（「入力中」「編集中」等）は画面ごとに Lane 2〜5 で決める。
  6. perPage 既定値（catalog ⑩ 裁定案）: 商品一覧は既定 100、棚卸しは既定 50（裁定案、owner 最終決定）。これを採ると何が変わるか: 棚卸しは未入力の見落としを減らすため 1 ページの走査量を絞り、商品一覧は 1 件探索の効率を優先してページ送り回数を減らす。40 刻み化は不採用の裁定案（既存 test 影響・移行コスト）。
