D の要点（差分のみ・番号付き未決項目）
  1. 総件数と現在位置を上にも（DSR-22）: 上部は「238 件中 1〜50 件目 · 1 / 5 ページ」を必須表示（Lane 2 実装済み canonical `Pagination` / `PaginationSummary`、旧 `ProductPagination.tsx:26-30`）、pager ボタンは任意で本 mockup では下部のみに置く（catalog ⑩ Don't）。範囲付き統一形は Lane 2 で実装済み（旧 `ProductPagination` + 全 caller + test を一括移行済み、規範も範囲付き統一形へ更新済み）。発動条件は viewport 超過時のみ（DSR-22 で確定、未決事項なし）— これを採ると何が変わるか: 長い一覧で「いま何件目か」を下までスクロールせずに確認でき、同じ操作ボタンを 2 組出さないため判断コストも増えない。
  2. table header を sticky: 発動条件は viewport 超過時のみ（DSR-22）。列名が常に見える。これを採ると何が変わるか: 横スクロール中も列の意味を見失わない。sticky header の背景色は `--d-head`（= 実装 `--list-head`、stone-200 相当、#e7e5e4）を採用（Gated Amendment 2 S11、owner L3 run 1 FAIL-3 是正。旧採用案の `bg-muted`〈stone-100、#f5f5f4〉は本文の `--card`/`--muted` と近く sticky 帯が浮き上がらなかったため変更、`ListShell` の summary 帯 + `thead th` + `thead tr`）。機構差分（Lane 2 実装で不採用にしたもの、注記のみ）: 本 mockup の箱内スクロール（`.tbl > .scroll{max-height:56vh}`）は不採用 — DSR-17 の `
    ` 単一 scroll container と衝突するため。表の外枠（`.tbl` の `border-radius:8px; overflow:hidden`）も不採用 — `overflow:hidden` が `
    ` 相対の sticky を殺すため。th の文字色は本 mockup の `--muted`（薄い灰）ではなく実装では `text-foreground` を維持（`--muted-foreground` 対 `bg-muted` 4.40:1 は 14px の 4.5:1 未達のため）。
  3. 識別列（商品コード + 商品名）を左固定: 発動条件は横 overflow 発生時のみ、mapping は DSR-22 表を正本とする（未決事項なし）。横スクロール時に右端へ影。
  4. 操作枠・構造線のコントラスト（DSR-22 原則 13）: 構造線 `--border` を一段濃く、操作枠 `--border-strong` を新設。実装済み（`--border` #cdc8c4 / `--border-strong` #8a8480、値は 00-foundations カラーパレット表が正本）。
  5. 現在行 3 点（DSR-22 原則 15）: 左 4px バー + 淡い背景 `--row-current` + badge/文言。表内の 3 行目に適用例あり（下にスクロールして確認）。badge/文言の具体的な語彙（「入力中」「編集中」等）は画面ごとに Lane 2〜5 で決める。
  6. perPage 既定値（catalog ⑩ 裁定案、owner 了承 2026-09-03）: 商品一覧は既定 100、棚卸しは既定 50。これを採ると何が変わるか: 棚卸しは未入力の見落としを減らすため 1 ページの走査量を絞り、商品一覧は 1 件探索の効率を優先してページ送り回数を減らす。40 刻み化は不採用の裁定案（既存 test 影響・移行コスト）。
  7. 廃番 Badge の可読性（DSR-22 原則 13、owner Human Gate 所感 2026-09-03）: soft 背景のみの分類 pill は白地で見づらいため、枠線（`--border-strong` 相当、対 `--background` 実測 3.53:1）+ icon を追加した。これを採ると何が変わるか: 枠線と icon で「廃番」であることが白地でも判別できる。既存の灰色系 secondary Badge（実装済み画面）も同根の可読性課題があり、Lane 3〜5 の sweep 項目とする。
