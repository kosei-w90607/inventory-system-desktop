## Failure Modes

- 依存の更新の順序で root の `zod` が 4.6.5 へ hoist され、BIZ-01-D5 の数え方が変わる（packet の Contract Probe P3 で実際に起きた）。
- `seroval-plugins` だけが 1.6 に上がり、`seroval` が 1.5 に残って build と route の test が import error で落ちる（同 P4 で実際に起きた）。
- `@tanstack/react-router` を名指しせずに入れ、npm が peer に合わせて別の版（probe では 1.170.40）を選び、`@tanstack/router-core` が 2 つの版に割れる（同 P3 の前段の probe で起きた）。
- markdownlint-cli2 を外した後に smol-toml の override を残し、`package.json` に使われない `overrides` が残る。
- `source-map-js@1.2.2` の cooldown 中に Scope の 8 を回し、"up to date" の exit 0 を成功と取り違えて 1.2.1 のまま進む。
- 起票の後に advisory DB が変わり、AC1b の列に無い advisory が出たまま Scope の外で進む（Scope の 0 の停止条件）。
- 範囲外の package（vite・vitest・eslint・prettier・typescript・react）が一緒に動き、gate の物差しが変わる。
- 修正版の無い braces の high を「消えた」と報告する。
- vulnerable な package が runtime の依存に入る。

## Mutation-style Adequacy Questions

本 lane は production の code を変えないので、mutation は依存の解決の失敗の型で答える。

- If a key branch is inverted, which test fails?: root の `zod` が上がる型は AC8 の test が red（P3 で実測）。
- If a guard is removed, which test fails?: Scope の 7 を抜くと `npm run build` が red（P4 で実測）。library の `useBlocker` が `history.block(` の登録を省くと `src/hooks/useUnsavedChangesWarning.router.test.tsx` が red（P10 で実測。mock の `src/hooks/useUnsavedChangesWarning.test.tsx` は green のまま）。
- If an output field is omitted, which test fails?: router-core の export が消えると typecheck と `SP4` が red。
- 他の問い（mock 値・invalidate/refetch・threshold・output order・dry-run・safe integer・state token）は not applicable: production の code と data の経路を変えない。
