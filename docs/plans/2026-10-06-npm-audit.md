## Goal

Goal Invariant:

### 最小完了条件

- 開発用依存の high のうち、修正版が出ているもの（`@tanstack/router-cli`・`@tanstack/router-plugin`・`chokidar`・`brace-expansion`）が `npm audit` から消え、修正版の無い braces の経路（markdownlint-cli2 経由）は owner の Q1 の選択どおりに消えるか、理由と見直しの条件つきで残る。
- アプリの振舞いは変わらない（frontend の全 gate が通り、runtime の `zod` は 4.3.6 のまま、route と scroll 復元の契約の test が通る）。

### 失敗定義

- `npm audit fix`（`--force` を含む）・名指しでない `npm update`・`min-release-age-exclude[]` を使った。
- runtime の `zod` が 4.3.6 から動いた、または `@tanstack/router-core` が 2 つの版に割れた、または `seroval` と `seroval-plugins` の版が食い違う（下の Contract Probe P3・P4 の失敗）。
- frontend の gate のどれかが落ちる、または既存の test を弱めて通した。
- 修正版の無い high を「消えた」と報告した。

### 非目的

- `zod` を 4.4 以上へ上げること（Contract Probe P3 で REQ-301 / BIZ-01-D5 の test が落ちた。別の lane）。
- TanStack の他の package（`@tanstack/react-router-devtools`・`@tanstack/react-query*`）や typescript-eslint・eslint を最新へ上げること。
- 監視（`scripts/npm-security-monitor.sh`・`.github/workflows/npm-security-monitor.yml`）と CI の audit step の変更。

## Boundary / Wire Contract

- producer: Writer の名指しの npm 操作（Scope の 1〜8）。
- consumer: `npm ci --ignore-scripts`（CI・local full・DEV_SETUP）、vite / vitest / tsr の実行時の module 解決、配布 build の bundle。
- wire type: `package.json`（依存の spec）と `package-lock.json`（lockfileVersion は変えない）。
- internal type: node_modules の解決木。
- precision/range: 直接依存は exact（`--save-exact`）。推移依存は親の range の中で cooldown を満たす版。
- round-trip path: `npm ci --ignore-scripts` が同じ木を再現する（AC9）。
- invalid input: 7 日未満の版は `min-release-age=7` が解決しない。範囲外の package の差分は Scope の停止条件。
- compatibility: `.npmrc` は不変（AC6）。runtime の公開 API の利用箇所は typecheck と test で確かめる（AC7）。
