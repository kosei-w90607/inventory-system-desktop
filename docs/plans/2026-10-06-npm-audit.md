## Boundary / Wire Contract

- producer: Writer の npm 操作（Scope の 0〜8。変更の command は名指しか、3 の引数無しの `npm install`）。
- consumer: `npm ci --ignore-scripts`（CI・local full・DEV_SETUP）、vite / vitest / tsr の実行時の module 解決、配布 build の bundle。
- wire type: `package.json`（依存の spec）と `package-lock.json`（lockfileVersion は変えない）。
- internal type: node_modules の解決木。
- precision/range: 直接依存は exact（`--save-exact`）。推移依存は親の range の中で cooldown を満たす版。
- round-trip path: `npm ci --ignore-scripts` が同じ木を再現する（AC9）。
- invalid input: 7 日未満の版は `min-release-age=7` が解決しない。範囲外の package の差分は Scope の停止条件。
- compatibility: `.npmrc` は不変（AC6）。runtime の公開 API の利用箇所は typecheck と test で確かめる（AC7）。
